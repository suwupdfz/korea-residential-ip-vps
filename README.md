## 原生 IP、双 ISP、住宅 IP：三个词不是一回事

搜「韩国住宅IP VPS」的人，多半已经知道「机器要在韩国」，真正纠结的是 IP 属性够不够「像本地人」。

原生 IP 说的是 IP 的归属链路：这个 IP 段由韩国本土运营商分配，ASN 查询结果指向韩国 ISP，而不是从别处申请、再由机房宣告到韩国节点。原生 IP 不一定带住宅属性，很多机房 IP 也能做到 ASN 落在韩国。

双 ISP 是数据库层面的登记结果：这个 IP 在 IP 归属库里被记录为两个运营商归属，通常出现在家庭宽带段上。它比单纯的「原生」更接近真实用户，但仍然是数据库判断，不是平台风控的最终结论。

住宅 IP 更进一步，要求这个 IP 本身属于家庭宽带网段。三者是层层递进的关系，越往后越贵，也越难批量拿到。

WePC 的 SEJONG 套餐同时写了「双ISP」和「家宽」，属于三者里定位最高的那一档。第三方测评账号在 2026 年 10 月底发布过一组实测，称该 IP 在多数检测平台被识别为住宅网络，Netflix、Disney+ 韩国区解锁正常，韩国 AI 平台访问正常，YouTube 4K 播放流畅。这些是测评者的结论，不是官方承诺，也不是本文的实测结果。

## 开通后 48 小时内该验的几项

拿到机器先别急着上业务，按这个顺序过一遍。IP 不合格的话，越早发现越好处理。

1. **查 ASN 归属。** 用 ipinfo.io 或 ip.sb 查，确认 ASN 指向韩国本土 ISP，而不是云服务商。
2. **查风险分。** scamalytics.com 看 IP 的风险评分，住宅 IP 通常落在较低区间。分数偏高说明这个 IP 可能被前人用过。
3. **查流媒体 region。** 登录 Netflix、Disney+ 看实际落区，别只看能不能打开。
4. **单独验 TikTok。** 第三方测评已经出现过「IP 在韩国、TikTok 判新加坡」的情况，自己拿目标账号跑一遍比什么都准。
5. **测三网延迟与回程。** 电信、移动方向应该直连，联通方向预期会绕。用 ping 和 traceroute 各跑一次，确认绕的程度你能接受。
6. **测带宽。** speedtest 跑一遍，看是否接近 100Mbps 标称值。
7. **确认协议合规。** 官网禁用 Shadowsocks，搭建方式按它给的教程走，别自己发挥。

有一件事要提前想明白：WePC 韩国产品页没有写免费换 IP 的政策。IP 不干净、被平台标记，能不能换、怎么收费，只能开工单问。这也是为什么上面那几项验证要在收到机器后立刻做，别等用了一个月才发现 IP 有问题。
